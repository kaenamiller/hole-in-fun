# Shared implementation contracts

Use Godot 4.7 GDScript. Prefer explicit types or `=` over `:=` when a value comes from a Dictionary or untyped external object (warnings must not prevent parsing). Each agent owns only its assigned files. Do not modify project.godot or main.gd.

Coordinates: Vector3 world positions, y up; property x,z 0..1024, grid 4m. Terrain surfaces integers: 0 rough, 1 fairway, 2 green, 3 tee, 4 sand, 5 water, 6 decorative. Terrain API (root implements): height_at(Vector3)->float, surface_at(Vector3)->int, slope_at(Vector3)->Vector2, playable(Vector3)->bool, segment_blocked(Vector3,Vector3)->bool (trees/objects), beauty_at(Vector3)->float, route(Vector3,Vector3,cart:bool=false)->PackedVector3Array, nearest_safe(Vector3)->Vector3, penalty_drop(Vector3,Vector3)->Vector3, condition_at(Vector3)->float, course_wear()->float, hole_condition(hole:Dictionary)->Dictionary with green/fairway/tee/bunkers means, apply_wear_at(Vector3,float), restore_condition_at(Vector3,float,neighborhood:int=0), overnight_decay(has_maintenance_shed:bool), green_cells(hole:Dictionary)->PackedInt32Array (connected surface-2 fill from cup), green_owner(p:Vector3)->int, on_green(p:Vector3,hole:Dictionary)->bool, green_area(hole:Dictionary)->float, green_slope_stats(hole:Dictionary)->Dictionary, disconnected_green_paint(hole:Dictionary)->PackedInt32Array, green_outline_points(hole:Dictionary)->PackedVector3Array, bunkers()->Array[Dictionary] with cells/centre/area/depth, bunker_at(p:Vector3)->Dictionary, zone_at(p:Vector3,hole:Dictionary={})->String ("ob"|"penalty"|""), plan_green_contour/ plan_bunker_shape brushes. terrain.holes Array[Dictionary], terrain.objects Array[Dictionary]. Hole dictionary: id:int,name:String,tee:Vector3,cup:Vector3,green_radius:float,par:int,open:bool,waypoints:Array[Vector3], optional pins:Array[Vector3] (up to 4), pin_index:int (daily rotation), tees:Array[{pos:Vector3,name:"forward"|"middle"|"back"}]. Object dictionary: id:int,kind:String,pos:Vector3,rotation:float,condition:float (0..1),cleanliness:float (0..1), optional end:Vector3 for bridge/path/ob_stakes/penalty_stakes. Terrain fields: entrance:Vector3, palette:PackedColorArray (7 surface colours), cost_multipliers:Dictionary (raise, fairway, water, clear_tree), map_id:String, rough_name:String, water_color:Color, heights:PackedFloat32Array,surfaces:PackedByteArray,condition:PackedFloat32Array (per-cell 0..1, 1 pristine),wear:float derived via course_wear() (0 pristine, 1 exhausted),revision:int. terrain.touch() invalidates routing caches.

MapGenerator (root): class_name MapGenerator extends RefCounted. static generate(definition:Dictionary)->TerrainModel; static preview_texture(definition, preview_seed:int=-1)->ImageTexture.

Catalog (agent): static maps()->Array map presets; static map(id:String)->Dictionary.

AssetFactory (agent): class_name AssetFactory extends RefCounted. static build(kind:String, variant:int=0)->Node3D, static golfer(variant:int=0)->Node3D, static cart()->Node3D, static animate_golfer(node:Node3D,activity:String,phase:float)->void. Models centered at origin and ground y=0. Asset footprint definitions in Catalog (agent): class_name Catalog extends RefCounted; static buildings()->Array (dict entries id,name,cost,upkeep,radius,capacity,grade,benefit); static scenery()->Array (id,name,cost,upkeep,radius,grade,set,beauty,influence); static staff_roles()->Array; static loans()->Array; static events()->Array; static find(kind:String)->Dictionary. Generate reusable meshes/materials; plain dictionaries acceptable at API, typed definition resource classes encouraged internally.

ShotEngine (agent): class_name ShotEngine extends RefCounted. static shot(terrain, start:Vector3, hole:Dictionary, skill:float, rng:RandomNumberGenerator)->Dictionary. Returns start:Vector3, landing:Vector3, end:Vector3, target:Vector3, arc:float, duration:float, club:String, penalty:int, holed:bool, hazard:bool, reason:String (includes ob_penalty, penalty_drop, water_recovery, sand_lie, green_hit, holed_*, layup, safe_side, carry_hazard, lag_putt), plan:String ("aggressive"|"conservative"|"neutral"), contested:bool, layup:bool. Target is chosen by expected remaining strokes over a bounded candidate set (pin, fat of green, layup, carry, tree sidestep) using the same miss ellipse as execution; skill scales both predicted dispersion and risk aversion. On-green uses terrain.on_green when available (surface 2 plus green_owner). OB: stroke-and-distance to start with +1 penalty. Penalty areas and water: +1 penalty with penalty_drop when available. Bunker depth reduces recovery carry and roll. Green slope adds putt scatter. static effective_cup(hole)->Vector3. static round_preview/analyze unchanged contract.

ResortSimulation (agent): class_name ResortSimulation extends RefCounted. func setup(terrain_ref,sandbox_mode:bool,starter:bool,map_def:Dictionary={})->void. func tick(dt:float)->void. terrain provided above; Catalog and ShotEngine available. Fields guests:Array[Dictionary],staff:Array[Dictionary],groups:Array[Dictionary],cash:float,day:int,minute:float,sandbox:bool,prices:Dictionary,ledger:Array[Dictionary],loans:Array[Dictionary],scheduled_events:Array[Dictionary],event_history:Array[Dictionary],grade:int,publicity:float,open:bool,satisfaction:float,completed_visits:int,notice:String,analytics:AnalyticsGrid. Individual guests id,name,pos:Vector3,destination:Vector3,activity:String,skill:float,mood:float (0..1),hunger:float (0..1),energy:float (0..1),restroom:float (0..1),budget:float,spent:float,group_id:int,hole_index:int,strokes:int,scorecard:Array,thought:String,cart:bool,shot:Dictionary (empty unless animating),shot_elapsed:float, route:PackedVector3Array, optional cart_pos:Vector3. Staff id,name,role,pos:Vector3,activity,assignment (-1 auto or {"kind":"hole"|"object","id":int}), wage:float. Methods charge(amount:float,category:String,description:String)->bool, credit(amount:float,category:String,description:String), hire(role:String)->bool, fire(id:int), assign_staff(id:int,assignment), borrow(product:String)->String, repay(loan_id:int,amount:float)->String, schedule_event(kind:String,days_ahead:int=1)->String, grade_requirements()->String, on_construction(center:Vector3,radius:float,removed_hole_id:int=-1) (root calls AFTER applied edits; relocation and compensation, no stranded guests), snapshot()->Dictionary, restore(data:Dictionary). All ids monotonic. Save includes RNG state. Signal-free polling UI. Currency $, minute is 0..600 operating day starting at 7am, dt unit simulated seconds, 1 real second advances 1 simulated minute (tick(60)). Tick must substep internally or robustly handle large dt. Agent may add methods used by tests. Additional files tests/test_simulation.gd docs/SIMULATION.md.

AnalyticsGrid (agent): class_name AnalyticsGrid extends RefCounted. 64x64 float grids (16 m cells) keyed by layer name. Methods add(layer:String,pos:Vector3,amount:float), decay(layer:String,factor:float), value(layer,pos:Vector3)->float, max_value(layer)->float, snapshot()->Dictionary, restore(data:Dictionary). ResortSimulation owns sim.analytics; layers include traffic, cart_traffic, waiting, landings, hazard_landings. Daily decay in _end_day: traffic/cart_traffic x0.6, waiting x0.5, landings/hazard_landings x0.7. File scripts/analytics_grid.gd.

Root owns terrain_model.gd (RefCounted class_name TerrainModel), terrain_view.gd, main.gd, camera, UI, persistence, project setup, exports and integration tests. Root will connect models and present golfer shot interpolation in view. Simulation should keep interpolated person pos current and emit plain state only, no Node creation.
