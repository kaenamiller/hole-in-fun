# Shared implementation contracts

Use Godot 4.7 GDScript. Prefer explicit types or `=` over `:=` when a value comes from a Dictionary or untyped external object (warnings must not prevent parsing). Each agent owns only its assigned files. Do not modify project.godot or main.gd.

Coordinates: Vector3 world positions, y up; property x,z 0..1024, grid 4m. Terrain surfaces integers: 0 rough, 1 fairway, 2 green, 3 tee, 4 sand, 5 water, 6 decorative. Terrain API (root implements): height_at(Vector3)->float, surface_at(Vector3)->int, slope_at(Vector3)->Vector2, playable(Vector3)->bool, segment_blocked(Vector3,Vector3)->bool (trees/objects), beauty_at(Vector3)->float, route(Vector3,Vector3,cart:bool=false)->PackedVector3Array, nearest_safe(Vector3)->Vector3. `terrain.holes` Array[Dictionary], `terrain.objects` Array[Dictionary]. Hole dictionary: id:int,name:String,tee:Vector3,cup:Vector3,green_radius:float,par:int,open:bool,waypoints:Array[Vector3]. Object dictionary: id:int,kind:String,pos:Vector3,rotation:float,condition:float (0..1),cleanliness:float (0..1), optional end:Vector3 for bridge/path. Terrain fields: heights:PackedFloat32Array,surfaces:PackedByteArray,wear:float (0 pristine, 1 exhausted),revision:int. terrain.touch() invalidates routing caches.

AssetFactory (agent): class_name AssetFactory extends RefCounted. static build(kind:String, variant:int=0)->Node3D, static golfer(variant:int=0)->Node3D, static cart()->Node3D, static animate_golfer(node:Node3D,activity:String,phase:float)->void. Models centered at origin and ground y=0. Asset footprint definitions in Catalog (agent): class_name Catalog extends RefCounted; static buildings()->Array (dict entries id,name,cost,upkeep,radius,capacity,grade,benefit); static scenery()->Array (id,name,cost,upkeep,radius,grade,set,beauty,influence); static staff_roles()->Array; static loans()->Array; static events()->Array; static find(kind:String)->Dictionary. Generate reusable meshes/materials; plain dictionaries acceptable at API, typed definition resource classes encouraged internally.

ShotEngine (agent): class_name ShotEngine extends RefCounted. static shot(terrain, start:Vector3, hole:Dictionary, skill:float, rng:RandomNumberGenerator)->Dictionary. Returns start:Vector3, landing:Vector3, end:Vector3, target:Vector3, arc:float, duration:float, club:String, penalty:int, holed:bool, hazard:bool, reason:String. skill 0..1. static round_preview(terrain,hole:Dictionary,skill:float,seed_value:int)->Dictionary returns strokes:int,hazards:int,shots:Array. static analyze(terrain,hole:Dictionary,count:int=30,seed_value:int=42)->Array three dictionaries label,skill,average,hazard_rate,shots (flattened sample shot dictionaries). Use same shot for real golf. Maximum 14 strokes per hole. Files scripts/shot_engine.gd tests/test_shots.gd.

ResortSimulation (agent): class_name ResortSimulation extends RefCounted. func setup(terrain_ref,sandbox_mode:bool,starter:bool)->void. func tick(dt:float)->void. terrain provided above; Catalog and ShotEngine available. Fields guests:Array[Dictionary],staff:Array[Dictionary],groups:Array[Dictionary],cash:float,day:int,minute:float,sandbox:bool,prices:Dictionary,ledger:Array[Dictionary],loans:Array[Dictionary],scheduled_events:Array[Dictionary],event_history:Array[Dictionary],grade:int,publicity:float,open:bool,satisfaction:float,completed_visits:int,notice:String. Individual guests id,name,pos:Vector3,destination:Vector3,activity:String,skill:float,mood:float (0..1),hunger:float (0..1),energy:float (0..1),restroom:float (0..1),budget:float,spent:float,group_id:int,hole_index:int,strokes:int,scorecard:Array,thought:String,cart:bool,shot:Dictionary (empty unless animating),shot_elapsed:float, route:PackedVector3Array, optional cart_pos:Vector3. Staff id,name,role,pos:Vector3,activity,assignment:int (-1 auto), wage:float. Methods charge(amount:float,category:String,description:String)->bool, credit(amount:float,category:String,description:String), hire(role:String)->bool, fire(id:int), assign_staff(id:int,object_id:int), borrow(product:String)->String, repay(loan_id:int,amount:float)->String, schedule_event(kind:String,days_ahead:int=1)->String, grade_requirements()->String, on_construction(center:Vector3,radius:float,removed_hole_id:int=-1) (root calls AFTER applied edits; relocation and compensation, no stranded guests), snapshot()->Dictionary, restore(data:Dictionary). All ids monotonic. Save includes RNG state. Signal-free polling UI. Currency $, minute is 0..600 operating day starting at 7am, dt unit simulated seconds, 1 real second advances 1 simulated minute (tick(60)). Tick must substep internally or robustly handle large dt. Agent may add methods used by tests. Additional files tests/test_simulation.gd docs/SIMULATION.md.

Root owns terrain_model.gd (RefCounted class_name TerrainModel), terrain_view.gd, main.gd, camera, UI, persistence, project setup, exports and integration tests. Root will connect models and present golfer shot interpolation in view. Simulation should keep interpolated person pos current and emit plain state only, no Node creation.
